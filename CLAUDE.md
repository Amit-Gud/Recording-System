# Recording System — CLAUDE.md

## Project Overview

A screen recording and replay system designed for enterprise environments.
- **Agents** run on Windows endpoints and continuously capture screen content (including mouse cursors).
- **Central Server** receives, stores, and indexes the recording streams.
- **Replay Client** allows authorized users to play back sessions.
